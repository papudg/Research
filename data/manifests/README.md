## Export

After placing the item-bank fixture, regenerate manifests from the repository root:

```powershell
$env:PYTHONHASHSEED='0'
python scripts/export_manifests.py
```

Manifests are derived deterministically from the fixture chapter list and section template; exporting captures the exact JSON used for independent verification without re-running the generator.
